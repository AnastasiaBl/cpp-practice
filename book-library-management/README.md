# Book Library Management System

Учебный проект на C++, представляющий собой консольную систему управления библиотекой. Реализован с использованием классов, конструкторов, динамической памяти и методов для управления объектами книг.

## Цель проекта

Изучить создание и инициализацию объектов с помощью конструктора класса, закрепить принципы инкапсуляции и освоить динамическое управление памятью при работе с коллекцией объектов.

## Основные возможности

### 1. Класс `Book`

Класс описывает книгу и содержит следующие приватные поля:

- `_genre` — жанр книги;
- `_author` — автор;
- `_title` — название;
- `_year_of_publication` — год издания;
- `_price` — цена.

**Конструктор `Book()`** принимает параметры и инициализирует все поля нового объекта.

Для изменения данных предусмотрены методы:

- `set_author()` — изменение автора;
- `set_title()` — изменение названия;
- `set_genre()` — изменение жанра;
- `set_year()` — изменение года издания;
- `set_price()` — изменение цены.

Метод `all_book()` выводит полную информацию о книге.

### 2. Класс `Library`

Класс управляет коллекцией объектов `Book`.

Основные поля:

- `book_n` — динамический массив указателей на объекты книг;
- `size` — количество книг в библиотеке.

Реализованные методы:

| Метод | Назначение |
|---|---|
| `Library()` | Инициализация пустой библиотеки |
| `get_size()` | Получение количества книг |
| `add_book()` | Добавление новой книги |
| `book()` | Вывод всех книг |
| `book_id()` | Просмотр книги по номеру |
| `delete_book()` | Удаление одной книги |
| `delete_all()` | Удаление всех книг |
| `~Library()` | Освобождение динамической памяти |

### 3. Главное меню

Программа предоставляет следующие операции:

1. Добавление книги.
2. Просмотр всех книг.
3. Просмотр книги по номеру.
4. Удаление книги по номеру.
5. Удаление всех книг.

Для ввода целых чисел и строк предусмотрены вспомогательные функции проверки и обработки пользовательского ввода.

## Ограничения текущей реализации

- Поля книги закрыты модификатором `private`, но публичные методы чтения отдельных полей отсутствуют. Просмотр доступен через `all_book()`.
- Методы изменения полей (`set_author()`, `set_title()` и другие) реализованы, но не подключены к меню. Редактирование книг через интерфейс не предусмотрено.
- Для хранения книг используется ручное управление памятью через `new` и `delete`, что требует внимательного контроля времени жизни объектов.
- Класс `Library` не запрещает копирование объектов. Стандартное копирование указателей может привести к двойному освобождению памяти.
- Проверка года издания и цены на допустимые значения не реализована.
- Переменная `id` объявлена глобально, хотя её можно использовать локально.
- В меню проверяется диапазон от 1 до 6, хотя реализовано только пять операций.

## Возможные улучшения

- Заменить `Book**` на `std::vector<Book>` или `std::vector<std::unique_ptr<Book>>`.
- Добавить редактирование информации о книге через меню.
- Реализовать проверку года издания и цены.
- Убрать глобальные переменные.
- Добавить обработку исключений при выделении динамической памяти.
- Реализовать безопасное копирование или запрет копирования объектов `Library`.
- Разделить объявления классов и реализацию методов по заголовочным и исходным файлам.

## Назначение

Проект предназначен для изучения конструкторов классов, управления объектами и динамической памятью на примере простой системы учёта книг.

Реализация носит учебный характер.
