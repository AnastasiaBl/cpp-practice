# Programming Practice

A collection of educational C++ projects focused on programming fundamentals, algorithms, object-oriented programming, data structures, file processing, networking and information security.

The repository documents practical exercises and implementations developed during programming and information security studies.

## Projects

### 1. C++ Basics and Caesar Cipher

**Folder:** `01-basics-and-caesar-cipher/`

C++ fundamentals, including variables, arrays, functions and a basic Caesar cipher implementation.

**Topics:** Variables, arrays, functions, string manipulation, classical cryptography.

### 2. Array Filtering and Sorting

**Folder:** `cpp-array-filtering-and-sorting/`

Working with dynamic arrays, `std::vector` and `std::variant`, including input and output of different data types.

**Topics:** Dynamic arrays, STL, variants, data types, sorting algorithms.

### 3. Two-Dimensional Arrays and Matrix Operations

**Folder:** `cpp-two-dimensional-arrays/`

Working with two-dimensional arrays, matrix generation, element searching, random values and matrix transformations.

**Topics:** 2D arrays, matrices, random generation, algorithms, data processing.

### 4. DES Feistel Function Components

**Folder:** `des-feistel-function/`

Educational implementation of selected DES round-function components: expansion permutation, S-box substitution and P-permutation.

**Topics:** DES, Feistel networks, S-boxes, permutations, cryptography.

### 5. Recursive Functions

**Folder:** `recursive-functions/`

Recursive implementations of factorial, the Tribonacci sequence and the Euclidean algorithm.

**Topics:** Recursion, mathematical algorithms, factorial, Tribonacci, GCD.

### 6. OOP and Extended Euclidean Algorithm

**Folder:** `oop-and-extended-euclidean/`

Object-oriented implementation of mathematical functions and exercises involving the extended Euclidean algorithm and modular arithmetic.

**Topics:** OOP, classes, encapsulation, recursion, modular arithmetic, number theory.

### 7. Custom Mathematical Library

**Folder:** `custom-mathematical-library/`

A custom C++ library containing modular exponentiation, square and cube root calculations, string processing and array rotation.

**Topics:** Modular exponentiation, numerical methods, string processing, arrays, custom libraries.

### 8. Book Library Management System

**Folder:** `book-library-management/`

A console-based book management application using classes, constructors, dynamic memory allocation and object management.

**Topics:** OOP, constructors, destructors, dynamic memory, object management.

### 9. Organization Management System

**Folder:** `inheritance-organization-management/`

An organization management model based on inheritance, with School, University and Company classes, people management and relationship records.

**Topics:** Inheritance, polymorphism, OOP, classes, dynamic memory.

### 10. Text File Analyzer

**Folder:** `text-file-analyzer/`

A text-processing application that reads files, counts lines, searches for the longest word, replaces digits and writes processed content to an output file.

**Topics:** File handling, streams, text processing, string manipulation.

### 11. RC4 Stream Cipher and Binary Converter

**Folder:** `rc4-stream-cipher/`

An educational RC4-inspired stream cipher implementation with binary and hexadecimal text conversion.

**Topics:** RC4, stream ciphers, KSA, PRGA, binary conversion, hexadecimal representation.

### 12. Diffie-Hellman Key Exchange Protocol

**Folder:** `diffie-hellman-key-exchange/`

An educational implementation of the Diffie-Hellman key exchange protocol using modular arithmetic and public/private parameter calculations.

**Topics:** Diffie-Hellman, key exchange, modular arithmetic, number theory, public-key cryptography.

### 13. ElGamal Encryption Scheme

**Folder:** `elgamal-encryption/`

An educational implementation of the ElGamal public-key encryption scheme, including parameter selection, key generation, message encoding, encryption and decryption.

**Topics:** ElGamal, public-key encryption, modular arithmetic, prime numbers, number theory.

### 14. RSA Encryption Scheme

**Folder:** `rsa-encryption/`

An educational implementation of RSA parameter generation, key calculations, message encoding and encryption.

**Topics:** RSA, public-key cryptography, modular arithmetic, prime numbers, encryption.

### 15. Digital Signature Verification Chat

**Folder:** `digital-signature-chat/`

A TCP client-server chat demonstrating RSA and ElGamal digital signatures, message hashing and signature verification.

**Topics:** Digital signatures, RSA, ElGamal, hashing, TCP, client-server architecture, multithreading, network programming.

### 16. Elliptic Curve Point Arithmetic (ECC)

**Folder:** `elliptic-curve-arithmetic/`

An educational implementation of elliptic curve point enumeration, coordinate grid visualization, point addition, point doubling and scalar multiplication over a finite field.

**Topics:** Elliptic curves, ECC mathematics, finite fields, modular arithmetic, point addition, scalar multiplication, number theory.

### 17. Random Permutation Matrix Cipher

**Folder:** `random-permutation-cipher/`

An educational text transposition program that uses a randomly shuffled matrix of character indices to rearrange text. Originally developed as an exercise on magic squares.

**Topics:** Matrix operations, permutations, transposition ciphers, randomization, text processing.

### 18. Speck-Inspired Encryption, CBC and MDC-2-Inspired Hashing

**Folder:** `speck-cbc-mdc2-cryptography/`

An educational implementation of Speck-inspired block encryption and decryption, CBC-style block chaining, and a custom MDC-2-inspired hash construction.

**Topics:** Block ciphers, Speck, CBC mode, hash functions, MDC-2 principles, bitwise operations, hexadecimal encoding, cryptography.

## Technologies and Concepts

- **Programming Language:** C++
- **Programming Paradigms:** Procedural programming, object-oriented programming
- **Data Structures:** Arrays, dynamic arrays, vectors, structures
- **Algorithms:** Sorting, searching, recursion, mathematical algorithms
- **Mathematics:** Number theory, modular arithmetic, finite fields, elliptic curves
- **Cryptography:** Caesar cipher, DES components, RC4-inspired stream cipher, Diffie-Hellman, ElGamal, RSA, digital signatures, elliptic curve arithmetic, block ciphers and hash constructions
- **Networking:** TCP client-server communication, multithreading
- **File Processing:** Input/output streams, text analysis
- **Randomization:** Pseudorandom number generation and permutation algorithms

## Purpose

This repository serves as a record of practical programming experience and the development of technical skills in C++, algorithms, mathematical methods, networking and information security.

The projects are primarily educational implementations. They are intended to demonstrate programming concepts and cryptographic principles rather than provide production-ready security solutions.
