# Programming Practice

## О репозитории

Репозиторий содержит учебные проекты и практические задания, выполненные в процессе изучения программирования и информационных технологий.

Основная цель — закрепление теоретических знаний, развитие навыков разработки программного обеспечения, алгоритмического мышления и решения практических технических задач.

## Направления изучения

- Основы программирования на C++.
- Работа с переменными, типами данных и структурами.
- Массивы, строки и функции.
- Алгоритмы обработки и преобразования данных.
- Реализация базовых алгоритмов шифрования.
- Разработка и тестирование программ.

## Структура репозитория

| Директория | Описание |

| `cpp-basics-and-caesar-cipher/` | Основы C++, работа с переменными, массивами, функциями и реализация шифра Цезаря |

## Используемые технологии

- **C++** — разработка учебных программ.
- **Git** — контроль версий.
- **GitHub** — хранение исходного кода и управление проектами.

## Организация проектов

Каждый проект располагается в отдельной директории и содержит:

- `README.md` — описание проекта, цели, задачи и используемые технологии.
- `src/` — исходный код программ.
- Дополнительные файлы, необходимые для работы проекта.

## Цели развития

Репозиторий развивается по мере изучения новых технологий и выполнения практических заданий.

Основные направления дальнейшего развития:

- Углубление знаний C++.
- Изучение алгоритмов и структур данных.
- Развитие навыков разработки и отладки программ.
- Изучение технологий информационной безопасности.
- Формирование технического портфолио.
