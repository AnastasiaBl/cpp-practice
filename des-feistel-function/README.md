# DES Feistel Function Implementation

## Описание проекта

Учебный проект на языке C++, посвящённый изучению структуры блочного шифра DES (Data Encryption Standard) и принципов обработки данных в раундовой функции.

Программа демонстрирует отдельные этапы преобразования 32-битного блока данных: расширяющую перестановку E, обработку восьми S-блоков и перестановку P.

Входные данные представлены в виде 32-битной последовательности, состоящей из нулей и единиц.

## Цель работы

Изучить принципы работы раундовой функции DES, освоить механизмы расширения битового блока, нелинейной подстановки с использованием S-блоков и перестановки битов.

## Задачи

1. Сформировать 32-битный блок исходных данных.
2. Предусмотреть три способа задания входного блока:
   - использование предустановленной последовательности;
   - случайная генерация битов;
   - ручной ввод пользователем.
3. Выполнить расширение исходного блока с 32 до 48 бит с использованием таблицы E.
4. Разделить расширенный блок на восемь групп по 6 бит.
5. Обработать каждую группу с помощью соответствующего S-блока.
6. Преобразовать результаты S-блоков в 4-битные последовательности.
7. Выполнить перестановку полученных 32 бит с использованием таблицы P.
8. Вывести результаты промежуточных преобразований.

## Используемые технологии

- **Язык программирования:** C++
- **Стандартные библиотеки:**
  - `<iostream>` — ввод и вывод данных.
  - `<ctime>` — получение системного времени.
  - `<cstdlib>` — генерация случайных чисел.
  - `<cstdint>` — типы целых чисел фиксированной ширины (требуется для `uint8_t`).

- **Криптографические механизмы:** DES E-expansion, S-box substitution, P-permutation.

## Теоретическая основа

DES — симметричный блочный алгоритм шифрования, использующий 64-битные блоки данных и 56-битный эффективный ключ.

Раундовая функция DES включает следующие основные этапы:

1. Расширение 32-битной правой половины блока до 48 бит.
2. Побитовое сложение по модулю 2 с 48-битным раундовым ключом.
3. Разделение результата на восемь 6-битных групп.
4. Нелинейное преобразование с использованием восьми S-блоков. Каждая группа преобразуется в 4 бита.
5. Перестановка полученных 32 бит с использованием таблицы P.

В данной программе реализованы расширение E, подстановка S и перестановка P. Этап XOR с раундовым ключом и остальные компоненты полного алгоритма DES не реализованы.

## Реализация

### 1. Формирование входного блока

В программе предусмотрено три варианта получения исходной последовательности:

- `choice == 1` — использование заранее заданного 32-битного блока.
- `choice == 2` — генерация случайной последовательности из 32 бит.
- `choice == 3` — ручной ввод каждого бита пользователем.

Функция `rands()` отвечает за случайное заполнение массива нулями и единицами.

### 2. Расширяющая перестановка E

Функция `expansionE()` преобразует исходный 32-битный блок в 48-битный.

Для преобразования используется таблица `__EP`, определяющая порядок выбора битов. Некоторые позиции повторяются, что обеспечивает расширение блока.

### 3. Разделение на группы

Функция `grouping()` разделяет 48-битную последовательность на восемь групп по 6 бит.

Каждая группа передаётся в функцию `processing()` для дальнейшей обработки соответствующим S-блоком.

### 4. Обработка S-блоками

В программе используется массив `__Sbox`, содержащий восемь таблиц подстановки DES.

Функция `processing()`:

- Формирует шестибитную группу.
- Выделяет первый и последний биты для определения строки S-блока.
- Использует четыре средних бита для определения столбца.
- Передаёт полученные индексы в функцию `binary()`.
- Получает результат подстановки и преобразует его в четырёхбитную последовательность.

Функция `binary()` выполняет преобразование двоичных индексов в десятичные значения и обращается к соответствующему S-блоку.

Функция `reversebinary()` преобразует десятичный результат S-блока обратно в четырёхбитное представление.

### 5. Перестановка P

Функция `permutation()` выполняет перестановку 32-битной последовательности в соответствии с таблицей `__P`.

Результатом является преобразованный блок после применения P-перестановки.

## Основные функции

| Функция | Назначение |
|---|---|
| `rands()` | Генерация случайной 32-битной последовательности |
| `printint()` | Вывод битовой последовательности |
| `binary()` | Получение индексов и значения S-блока |
| `reversebinary()` | Преобразование результата S-блока в 4 бита |
| `processing()` | Обработка одной шестибитной группы |
| `grouping()` | Разделение 48 бит на восемь групп |
| `expansionE()` | Расширяющая перестановка E |
| `permutation()` | Перестановка P |

## Ограничения реализации

Текущая версия представляет собой учебную реализацию отдельных компонентов раундовой функции DES.

В программе отсутствуют:
- Генерация и расписание раундовых ключей.
- XOR с раундовым ключом.
- Начальная и конечная перестановки DES.
- Полный цикл из 16 раундов сети Фейстеля.
- Формирование итогового зашифрованного блока.

Поэтому программу нельзя использовать как полноценную реализацию DES для защиты информации.

## Результат

Реализована программа, демонстрирующая основные преобразования данных, используемые в раундовой функции DES: расширение блока, обработку S-блоками и перестановку битов.

Проект позволяет на практике изучить табличные криптографические преобразования и принципы построения блочных алгоритмов шифрования.
