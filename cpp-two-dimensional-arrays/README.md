# Two-Dimensional Arrays and Matrix Operations

## Описание проекта

Учебный проект на языке C++, посвящённый работе с двумерными массивами, обработке символьных и числовых данных, поиску элементов и выполнению операций над матрицами.

В программе реализованы генерация случайных значений, перенос символов из строки в двумерный массив, поиск чётных чисел и гласных букв, а также формирование матрицы на основе двух одномерных массивов.

## Цель работы

Закрепить навыки работы с двумерными массивами, освоить алгоритмы поиска и обработки элементов, научиться организовывать программный код с использованием пользовательских функций.

## Задачи

1. Создать строку из 25 символов и перенести её содержимое в символьный двумерный массив размером 5×5.
2. Вывести заполненный массив в табличном формате.
3. Создать числовой двумерный массив 5×5, найти максимальное чётное число в каждой строке и разместить найденные значения на главной диагонали.
4. Создать символьный двумерный массив 5×5, найти и вывести гласные буквы.
5. Создать два одномерных массива с индексами строк и столбцов, сформировать на их основе двумерный массив с последовательными значениями.
6. Вынести основные операции обработки данных в отдельные пользовательские функции.

## Используемые технологии

- **Язык программирования:** C++
- **Стандартные библиотеки:**
  - `<iostream>` — ввод и вывод данных.
  - `<string>` — работа со строками.
  - `<cstdlib>` — генерация случайных значений.
  - `<ctime>` — инициализация генератора случайных чисел.
  - `<algorithm>` — сортировка элементов.
- **Основные конструкции:** двумерные массивы, циклы `for`, условные операторы, пользовательские функции.
- **Алгоритмы:** поиск максимального чётного элемента, поиск гласных букв, перестановка индексов.

## Реализация

### 1. Перенос строки в двумерный массив

Функция `arraystr()` переносит символы из строки `string` в двумерный символьный массив размером 5×5.

- Используется вложенный цикл `for`.
- Каждый символ записывается в соответствующую ячейку.
- Перенос выполняется последовательно, слева направо и сверху вниз.

Для корректной работы программа проверяет, что введённая строка содержит ровно 25 символов.

### 2. Вывод двумерных массивов

Функции `printchar()` и `printint()` обеспечивают табличное отображение символьных и целочисленных массивов.

Для обхода строк и столбцов используются вложенные циклы.

### 3. Генерация числовой матрицы

Функция `randomint()` заполняет двумерный массив 5×5 случайными целыми числами в диапазоне от 0 до 99.

Генератор случайных чисел инициализируется с помощью `srand(time(0))`.

### 4. Поиск чётных чисел и размещение на диагонали

Функция `even()` выполняет следующие операции:

1. Копирует исходную матрицу в результирующую.
2. Последовательно анализирует каждую строку.
3. Находит максимальное чётное значение в строке.
4. Размещает найденное значение на соответствующей позиции главной диагонали.
5. Если чётные числа отсутствуют, записывает в диагональную ячейку значение 0.

### 5. Поиск гласных букв

Функция `randomchar()` заполняет символьную матрицу случайными строчными буквами латинского алфавита.

Функция `vowels()` проверяет каждый элемент матрицы на принадлежность к набору гласных:

`a, e, i, o, u`

При обнаружении гласной буквы программа выводит её значение и координаты расположения в матрице.

### 6. Формирование матрицы на основе одномерных массивов

Функция `randomints()` формирует два одномерных массива с индексами строк и столбцов, после чего перемешивает их элементы.

Далее массивы сортируются с использованием `std::sort()`.

Функция `five()` использует полученные индексы для заполнения двумерного массива последовательными значениями от 1 до 25.

Таким образом формируется матрица, в которой значения размещаются в соответствии с индексами строк и столбцов.
