# Organization Management System

Учебный проект на C++, демонстрирующий применение наследования, полиморфизма и объектно-ориентированного программирования при разработке консольной системы управления людьми и организациями.

## Project Overview

В основе проекта находится базовый класс `Organization`, содержащий общие характеристики организаций. На его основе созданы три производных класса:

- `School` — школа;
- `University` — университет;
- `Company` — компания.

Каждый производный класс расширяет базовую модель дополнительными полями, характерными для соответствующего типа организации.

Помимо иерархии организаций, проект содержит классы для хранения информации о людях и связях между людьми и организациями.

## Implemented Features

### 1. Class Inheritance

- Базовый класс `Organization`.
- Производные классы `School`, `University` и `Company`.
- Наследование общих полей организации.
- Добавление специализированных характеристик для каждого типа организации.
- Переопределение виртуального метода `all_info_org()` для отображения информации о разных типах организаций.

### 2. People Management

Класс `People` предназначен для хранения информации о людях.

Реализованы операции:
- добавление записи о человеке;
- просмотр всех записей;
- поиск по идентификатору;
- удаление отдельной записи;
- удаление всех записей.

Хранимые данные: имя, фамилия, отчество, возраст, телефон и электронная почта.

### 3. Organization Management

Реализованы операции:
- добавление школы, университета или компании;
- просмотр всех организаций;
- просмотр организаций по типу;
- поиск организации по идентификатору;
- удаление отдельной организации;
- удаление всех организаций.

Дополнительные характеристики:
- **School:** количество учеников и тип школы.
- **University:** количество студентов, факультет и рейтинг.
- **Company:** отрасль, количество сотрудников и организационно-правовой статус.

### 4. Relationship Management

Класс `Connection` предназначен для хранения информации о связях между людьми и организациями.

В записи предусмотрены:
- должность;
- идентификатор человека;
- идентификатор организации.

Реализованы добавление, просмотр и удаление записей о связях.

### 5. Input Validation

Вспомогательные функции предназначены для проверки ввода:
- `check_int()` — проверка целочисленных значений;
- `check_float()` — проверка числовых значений;
- `input_int()` и `input_float()` — ввод числовых данных;
- `input_string()` — ввод строк.

## Current Limitations

Проект находится на учебной стадии разработки. В текущей реализации присутствуют ограничения, требующие дальнейшей доработки:

- Используются статические массивы указателей и ручное управление динамической памятью.
- В деструкторах классов `People`, `Organization` и `Connection` реализовано освобождение статических данных, что может приводить к повторному освобождению памяти.
- В функциях удаления организаций по типу нарушена логика фильтрации и обновления количества элементов.
- В классе `Connection` указатель на объект `People` не инициализируется, хотя используется при отображении информации о связи.
- Проверка выбора типа организации не обеспечивает корректный повторный ввод при ошибке.
- Функция `input_string()` безусловно пропускает символ ввода, что может приводить к потере первого символа строки.
- Для класса `University` не реализовано корректное сохранение переданного рейтинга.
- Не реализована полноценная проверка существования связанных идентификаторов человека и организации.
