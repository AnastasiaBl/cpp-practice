# Basics and Caesar Cipher

Учебный проект на C++, посвящённый изучению базовых конструкций языка и реализации шифра Цезаря.

## Project Overview

Проект объединяет практические задания по основам программирования на C++ и простым алгоритмам обработки текста.

Основные направления:
- работа с переменными и типами данных;
- использование массивов;
- создание и вызов функций;
- обработка пользовательского ввода;
- реализация шифра Цезаря;
- шифрование и дешифрование текста на русском языке.

## Implemented Features

### 1. C++ Fundamentals

- Работа с переменными типов `int`, `char`, `string`.
- Объявление и заполнение массивов.
- Создание функций с различными типами возвращаемых значений.
- Обработка пользовательского ввода.

### 2. Caesar Cipher

Реализация классического шифра Цезаря — алгоритма подстановки, при котором каждый символ заменяется символом, расположенным на определённое количество позиций дальше в алфавите.

В проекте представлены две реализации:
- `caesar_cipher.cpp` — первоначальная реализация шифра Цезаря.
- `caesar_ru.cpp` — отдельная реализация для русского алфавита с сохранением регистра символов.

В новой реализации предусмотрены функции шифрования и дешифрования текста с использованием числового ключа.

## Build and Run

Для компиляции можно использовать компилятор g++:

```bash
g++ src/caesar_ru.cpp -o caesar_ru
```

Запуск:

```bash
./caesar_ru
```

Для Windows:

```bash
caesar_ru.exe
```

## Limitations

- Английский алфавит в `caesar_ru.cpp` не реализован.
- В исходной версии русского алфавита отсутствует буква «ц».
- Формула дешифрования требует корректной нормализации отрицательного индекса.
- Обработка русских символов зависит от кодировки исходного файла и консоли. Использование UTF-8 требует отдельной обработки многобайтовых символов.
- Шифр Цезаря не обеспечивает криптографическую стойкость и предназначен исключительно для учебных целей.

## Learning Outcomes

- Закрепление синтаксиса и базовых конструкций C++.
- Практика работы со строками и массивами.
- Разработка функций для обработки текста.
- Изучение принципа работы шифров подстановки.
- Понимание циклического сдвига символов в алфавите.
