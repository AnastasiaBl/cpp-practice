# C++ Basics and Caesar Cipher

## Описание проекта

Учебный проект на языке C++, направленный на изучение базовых конструкций программирования и принципов работы с данными.

В рамках работы реализованы переменные различных типов, массивы, функции с разными типами возвращаемых значений, а также алгоритм шифрования текста методом Цезаря.

## Цель работы

Закрепить практические навыки программирования на C++: научиться объявлять и выводить переменные, работать с массивами и индексами, создавать пользовательские функции и реализовывать простые алгоритмы обработки текста.

## Задачи

1. Создать переменные типов `int`, `char` и `string`.
2. Организовать вывод переменных, включая посимвольный вывод строки.
3. Создать массивы типов `int` и `char`.
4. Выполнить вывод элементов массивов по индексам и с использованием циклов.
5. Реализовать функции с возвращаемыми типами `int`, `char` и `void`, выполняющие прибавление 20 к исходному значению.
6. Реализовать шифр Цезаря для латинского алфавита.

## Используемые технологии

- **Язык программирования:** C++
- **Стандартные библиотеки:** `<iostream>`, `<string>`
- **Основные конструкции:** переменные, массивы, циклы, условия, функции.
- **Работа с данными:** ввод и вывод, индексация массивов, обработка строк.
- **Алгоритмы:** шифр Цезаря.

## Реализация

### 1. Основы C++ — `basics.cpp`

Программа демонстрирует:

- Объявление и инициализацию переменных типов `int`, `char`, `string`.
- Вывод значений переменных.
- Посимвольный вывод строки с использованием цикла.
- Создание целочисленного и символьного массивов.
- Обращение к элементам массивов по индексам.
- Вывод содержимого массивов с помощью циклов.
- Получение пользовательского ввода и проверку индекса.
- Создание трех функций:
  - `int s(int a)` — возвращает целое число, увеличенное на 20.
  - `char u(char b)` — возвращает символ с увеличенным на 20 кодом.
  - `void m(int &c)` — изменяет исходную переменную через передачу по ссылке, увеличивая её значение на 20.

### 2. Шифр Цезаря — `caesar_cipher.cpp`

Реализован алгоритм шифрования Цезаря — метод моноалфавитной подстановки, при котором каждая буква заменяется другой буквой, расположенной на заданное количество позиций дальше в алфавите.

Программа:
- Принимает текст от пользователя.
- Получает значение сдвига.
- Обрабатывает символы с использованием циклов и условных конструкций.
- Выполняет циклический переход от конца алфавита к его началу.
- Сохраняет регистр букв.
- Оставляет символы, не входящие в латинский алфавит, без изменений.
- Выводит зашифрованный текст.
