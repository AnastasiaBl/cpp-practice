# Custom Mathematical Library

Учебный проект на C++, представляющий собой самодельную математическую библиотеку с функциями для выполнения математических вычислений, обработки строк и работы с массивами.

## Цель проекта

Разработать набор собственных функций для решения математических и алгоритмических задач, а также закрепить навыки работы с функциями, строками, динамической памятью и массивами в C++.

## Реализованные задачи

### 1. Возведение в степень по модулю

Функция `degree_modu()` вычисляет остаток от возведения числа в целую неотрицательную степень по заданному модулю.

\[
a^n \bmod m
\]

Используется алгоритм бинарного возведения в степень, который позволяет сократить количество умножений по сравнению с последовательным возведением.

Временная сложность: O(log n).

### 2. Вычисление квадратного корня

Функция `square_root()` вычисляет квадратный корень неотрицательного числа методом Ньютона.

Используется итерационная формула:

\[
x_{k+1}=\frac{1}{2}\left(x_k+\frac{a}{x_k}\right)
\]

Для отрицательных чисел предусмотрено сообщение об ошибке.

### 3. Вычисление кубического корня

Функция `cube_root(float x)` вычисляет кубический корень методом Ньютона.

Итерационная формула:

\[
x_{k+1}=x_k-\frac{x_k^3-a}{3x_k^2}
\]

Предусмотрена обработка отрицательных значений аргумента.

### 4. Обработка строк

Функция `string_processing()` разделяет введённую строку на отдельные элементы по разделителю `;`.

Каждое полученное слово записывается в отдельную ячейку массива строк.

Для хранения используется массив `string` фиксированной ёмкости — 1000 элементов.

### 5. Сдвиг массива вправо

Функция `array_of_n_elements()`:

- считывает строку и формирует из неё динамический символьный массив;
- выполняет циклический сдвиг элементов на одну позицию вправо;
- использует вспомогательный массив размером в один символ;
- выводит состояние массива после каждой операции;
- освобождает выделенную динамическую память.

## Структура программы

- `Self_made.h` — объявления функций и вспомогательных методов ввода.
- `main()` — запуск программы и управление меню.

## Используемые технологии

- C++

## Ограничения текущей реализации

- Функция `degree_modu()` не проверяет модуль на равенство нулю и не поддерживает отрицательную степень.
- При отрицательном основании результат может быть отрицательным из-за особенностей оператора `%` в C++.
- Умножение `a * a` и `c * a` в функции модульного возведения в степень может привести к переполнению типа `int`.
- В `square_root()` и `cube_root()` используется фиксированная точность по разности значений, что может приводить к проблемам сходимости и точности для очень больших или малых аргументов.
- Массив `e[1000]` в `string_processing()` не проверяет количество полученных элементов. При превышении ёмкости возможен выход за границы массива.
- В `array_of_n_elements()` выполняется N последовательных сдвигов массива из N элементов. После полного цикла массив возвращается к исходному состоянию.
- Для хранения временного элемента используется массив `char u[1]`, хотя достаточно одной переменной типа `char`.
- Ввод пустой строки и обработка пробелов не имеют отдельной логики.

## Возможные улучшения

- Добавить проверку корректности модуля и показателя степени.
- Использовать более широкий целочисленный тип или безопасное умножение по модулю.
- Применить `std::vector<std::string>` вместо массива фиксированной ёмкости.
- Реализовать сдвиг массива на заданное пользователем количество позиций с использованием операции остатка от деления.
- Заменить массив `char u[1]` обычной переменной.
- Добавить критерии остановки итераций, учитывающие точность вычислений и количество итераций.
- Подключить необходимые математические заголовки и использовать `std::abs` для вычислений с плавающей точкой.

## Назначение

Проект предназначен для практического изучения разработки собственных функций и реализации математических алгоритмов на C++.

Реализация носит учебный характер и не является полноценной универсальной математической библиотекой.
