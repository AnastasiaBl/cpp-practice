# Array Filtering and Sorting

## Описание проекта

Учебная программа на языке C++, посвящённая работе с динамическими контейнерами, различными типами данных и алгоритмами обработки массивов.

В текущей реализации используется динамический контейнер `std::vector` совместно с `std::variant`, что позволяет хранить элементы нескольких типов данных в одной коллекции.

## Цель работы

Изучить принципы создания и обработки массивов, освоить работу с динамическими контейнерами STL и реализовать операции фильтрации и сортировки элементов.

## Задачи

1. Создать массив с заданным пользователем количеством элементов и заполнить его.
2. Вывести чётные числа.
3. Вывести нечётные числа.
4. Вывести числа, кратные трём.
5. Отсортировать числа по возрастанию.
6. Отсортировать числа по убыванию.

## Используемые технологии

- **Язык программирования:** C++
- **Стандартные библиотеки:**
  - `<iostream>` — ввод и вывод данных.
  - `<string>` — работа со строками.
  - `<variant>` — хранение значений разных типов.
  - `<vector>` — динамические контейнеры.
  - `<algorithm>` — алгоритмы обработки данных.
  - `<type_traits>` — инструменты работы с типами.
  - `<limits>` — ограничения типов и обработка ввода.
- **Конструкции языка:** циклы, условные операторы, `switch`, range-based for.
- **STL:** `std::vector`, `std::variant`, `std::visit`.

## Реализация

### 1. Создание динамического контейнера

Для хранения элементов используется `std::vector`, позволяющий динамически изменять размер коллекции.

В качестве типа элементов применяется `std::variant`, поддерживающий следующие типы данных:

- `int` — целые числа;
- `char` — символы;
- `double` — вещественные числа;
- `string` — строки;
- `bool` — логические значения.

### 2. Заполнение контейнера

Программа запрашивает количество элементов, после чего предлагает пользователю выбрать тип данных для каждого элемента.

Для обработки выбора используется конструкция `switch`.

### 3. Ввод пользовательских данных

В зависимости от выбранного типа программа запрашивает соответствующее значение и добавляет его в контейнер с помощью `push_back()`.

### 4. Вывод элементов

Для перебора элементов используется range-based цикл `for`.

Функция `std::visit()` позволяет получить доступ к фактическому значению, хранящемуся внутри `std::variant`, и вывести его на экран.

## Планируемые операции обработки массива

Согласно условию задания, дальнейшая реализация предусматривает:

- фильтрацию чётных чисел;
- фильтрацию нечётных чисел;
- поиск чисел, кратных трём;
- сортировку по возрастанию;
- сортировку по убыванию.

**Примечание:** перечисленные операции являются требованиями задания и не реализованы в представленной версии исходного кода.
