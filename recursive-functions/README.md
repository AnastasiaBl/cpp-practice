# Recursive Functions

Учебный проект на C++, посвящённый изучению рекурсии и её применению для решения математических задач.

## Цель проекта

Изучить принцип работы рекурсивных функций и реализовать с их помощью вычисление факториала, последовательности Трибоначчи и наибольшего общего делителя двух чисел.

## Реализованные задачи

### 1. Вычисление факториала

Функция `factorial(int n)` рекурсивно вычисляет факториал целого неотрицательного числа.

Математическое определение:

\[
n! = n \cdot (n-1)!
\]

Базовый случай: `0! = 1` и `1! = 1`.

### 2. Числа Трибоначчи

Функция `tribonacci(int n)` вычисляет n-й элемент последовательности Трибоначчи.

В реализации используются начальные значения:

- T(0) = 0;
- T(1) = 1;
- T(2) = 1.

Каждый следующий элемент равен сумме трёх предыдущих:

\[
T(n) = T(n-1) + T(n-2) + T(n-3)
\]

### 3. Алгоритм Евклида

Функция `gcd(int a, int b)` рекурсивно вычисляет наибольший общий делитель двух целых чисел.

Используется соотношение:

\[
НОД(a,b) = НОД(b, a \bmod b)
\]

Рекурсия завершается при достижении нулевого второго аргумента.

## Структура программы

- `main()` — главное меню выбора задачи.
- `task_1()` — ввод данных и вычисление факториала.
- `task_2()` — ввод данных и вычисление числа Трибоначчи.
- `task_3()` — ввод двух чисел и вычисление НОД.
- `factorial()` — рекурсивное вычисление факториала.
- `tribonacci()` — рекурсивное вычисление числа Трибоначчи.
- `gcd()` — рекурсивная реализация алгоритма Евклида.
- `close()` — обработка выбора о продолжении или завершении программы.

## Используемые технологии

- C++
- Рекурсивные функции
- Потоки ввода и вывода (`iostream`)
- Обработка строкового ввода (`sstream`)
- Локализация (`locale`)

## Ограничения текущей реализации

- Функции факториала и Трибоначчи возвращают `int`, поэтому при больших значениях аргумента возможно переполнение.
- Функция факториала поддерживает `n = 0`, однако пользовательский ввод в `task_1()` принимает только положительные числа.
- Рекурсивная реализация Трибоначчи многократно вычисляет одни и те же значения. Её временная сложность экспоненциальная, поэтому для больших `n` вычисления становятся медленными.
- Функция `gcd()` не нормализует знак аргументов. Для корректной обработки отрицательных чисел рекомендуется использовать `abs()`.
- Повторный ввод организован через рекурсивный вызов функций `task_1()`, `task_2()` и `task_3()`, что может приводить к избыточному росту стека вызовов.
- Функция `close()` повторно вызывает `main()`, вместо того чтобы возвращать управление главному циклу программы.

## Возможные улучшения

- Заменить повторный вызов `main()` циклом управления меню.
- Организовать повторный ввод данных с помощью циклов.
- Использовать `long long` или более широкий целочисленный тип с проверкой переполнения.
- Оптимизировать вычисление чисел Трибоначчи с помощью мемоизации или итеративного алгоритма.
- Добавить корректную обработку отрицательных аргументов в алгоритме Евклида.
- Разделить вычислительную логику и пользовательский интерфейс.

## Назначение

Проект предназначен для практического изучения рекурсии, базовых алгоритмов и организации функций в C++.

Реализация является учебной и не предназначена для использования в качестве готовой библиотеки вычислений.
